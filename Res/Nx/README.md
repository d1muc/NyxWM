# .nx — язык интерфейса nyxWM

`.nx` — это текстовые файлы, которые описывают **визуал** nyxWM: панели, виджеты,
кнопки, фигуры, анимации. Редактируешь файл — сохраняешь — интерфейс
перестраивается сразу, без перезапуска приложения.

`.nx` отвечает только за внешний вид. Файл настроек `config.jsonc` не трогается:
он про поведение (хоткеи, отступы окон, game mode), `.nx` — про то, как всё
выглядит.

---

## 1. Где лежат файлы

Читаются две папки, обе рекурсивно, все файлы `*.nx`:

| Папка | Для чего |
|---|---|
| `Res\Nx\` рядом с `nyxWM.exe` | то, что идёт с программой: `theme.nx`, `bar.nx`, `examples.nx` |
| `%AppData%\nyxWM\nx\` | твои личные файлы. Папка создаётся сама |

Файлы из второй папки читаются **после** первой, поэтому твои значения
перекрывают встроенные. Порядок внутри папки — по алфавиту.

Что общего у всех файлов:

* **токены** (`$имя`) и **анимации** видны из любого файла — палитру удобно держать
  в `theme.nx` и менять её в одном месте;
* **поверхности** (`surface`) каждый файл объявляет свои. Одноимённая поверхность
  не заменяет чужую, а добавляется второй: старую гаси через `enabled: false`.

Один сломанный файл не ломает остальные: он пропускается, а причина пишется в
консоль/лог в виде `nx: имя.nx: путь: сообщение at строка:колонка`.

### Горячая перезагрузка

Файлы отслеживаются. Сохранил — вся система пересобралась заново за один кадр.
Если после правки что-то пропало, смотри лог: почти всегда это опечатка с
указанием строки и колонки.

## 2. Как устроен файл

Три вида верхнего уровня: **токены**, **анимации**, **поверхности**.

```nx
// токен: имя и значение
accent: #7aa2f7

// анимация
animation pop:
    duration: 200ms
    easing: back-out
    {
        opacity: 0
        scale: 0.7
    }
    100% {
        opacity: 1
        scale: 1
    }

// поверхность со своими элементами
surface #bar:
    position: top
    height: 48

    row:
        gap: 10
        label:
            text: "привет"
```

**Отступы или фигурные скобки.** Тело элемента можно писать отступом (как выше)
или скобками — оба варианта равнозначны:

```nx
row:                   row: {
    gap: 10        ==       gap: 10
                           }
```

Смешивать внутри одного файла можно. Отступ — любой, важно только чтобы тело
было **глубже** заголовка. Скобочный вариант удобен для однострочников:
`row: { gap: 6 }`.

**Комментарии** — `//` до конца строки.

**Строка — это `ключ: значение`.** Если после `:` сразу идёт `{` или конец
строки, значит открывается тело элемента. Всё остальное — свойство.

## 3. Значения

| Что | Как пишется | Пример |
|---|---|---|
| Число | просто число | `14`, `-1`, `0.5` |
| Размер | число, `%` от родителя, `fill`, `flex`, `auto` | `width: fill`, `width: 50%` |
| Время | `ms` или `s` | `duration: 200ms`, `2s` |
| Цвет | `#rgb`, `#rrggbb`, `#aarrggbb` | `#7aa2f7`, `#cc12151c` |
| Строка | в кавычках, внутри можно `{выражение}` | `text: "{time.hm}"` |
| Список | `[a, b]` — два цвета дают градиент | `background: [$bg, $bg-soft]` |
| Логика | `true` / `false` | `bold: true` |
| Токен | `$имя` | `background: $bg` |

Важное про кавычки: **всё, что содержит `:` или `/`, пиши в кавычках.**

```nx
action: "command:explorer"   // правильно
icon: "icons/play.png"       // правильно
```

Без кавычек `command:explorer` распадётся на два токена, а `icons/play.png` —
на три (`/` в языке это оператор деления).

Прозрачность задаётся альфой в цвете: `#00000000` — совсем прозрачный,
`#80ffffff` — белый наполовину. Если `background` вообще не писать, фон
прозрачный.

## 4. Токены

Токен — это имя для значения. Объявляется на верхнем уровне, используется с `$`.

```nx
radius: 14
bg: #cc12151c

button:
    background: $bg
    radius: $radius
```

Токены из `theme.nx` (можешь менять все):

| Токен | Значение | Зачем |
|---|---|---|
| `$accent` | `#7aa2f7` | основной акцент |
| `$accent-soft` | `#4d7aa2f7` | он же, 30% альфы |
| `$fg` | `#e6e9ef` | основной текст |
| `$muted` | `#99a3b3` | второстепенный текст |
| `$ok` / `$warn` / `$bad` | зелёный / жёлтый / красный | состояния |
| `$bg` | `#cc12151c` | фон поверхностей |
| `$bg-soft` | `#991b1f2a` | фон, вторая половина градиента |
| `$bg-hover` | `#26ffffff` | подложка кнопок |
| `$stroke` | `#1fffffff` | обводка |
| `$radius` / `$radius-small` | `14` / `10` | скругления |
| `$gap` | `10` | промежуток в рядах |
| `$padding` | `8` | внутренние отступы |
| `$font` | `"Segoe UI"` | шрифт |
| `$size` / `$size-small` | `13` / `11` | размеры шрифта |

## 5. Элементы

Элемент — это `тип #имя:` и тело. Имя (`#имя`) необязательно, оно нужно только
чтобы понимать, что где.

| Тип | Что делает |
|---|---|
| `surface` | отдельное окно-поверхность (см. раздел 7) |
| `row`, `hstack` | ряд: дети слева направо |
| `column`, `vstack` | колонка: дети сверху вниз |
| `stack`, `canvas` | дети друг на друге |
| `widget`, `card`, `group` | колонка с рамкой, для группировки |
| `box`, `label` | прямоугольник с текстом и/или иконкой |
| `button` | то же плюс клик и наведение |
| `bar`, `progress` | полоса заполнения |
| `spacer`, `fill` | распорка: съедает свободное место |
| `divider`, `separator` | линия-разделитель |
| `circle`, `square`, `triangle`, `diamond`, `line` | та же коробка, но фигурой |
| `@время`, `@date`, `@track` | короткая запись для `label` с привязкой |

Фигуру можно задать и свойством: `shape: triangle` — то же, что `triangle:`.

Сокращения `@...` разворачиваются так: `@time` → `{time.hm}`, `@date` →
`{time.date}`, `@track` → `{media.title}`, `@artist` → `{media.artist}`,
`@cpu` → `{sys.cpu}`, `@ram` → `{sys.mem}`, `@battery` → `{sys.battery}`,
`@windows` → `{win.count}`.

## 6. Свойства оформления

Пишутся в теле элемента и наследуются детьми — задал на `row`, и все кнопки
внутри уже такие.

| Свойство | Что делает | Значения |
|---|---|---|
| `background`, `bg` | фон | цвет или `[цвет, цвет]` — градиент |
| `direction`, `gradient` | направление градиента | `vertical` (по умолчанию), `horizontal` |
| `foreground`, `fg`, `color` | цвет текста и иконки | цвет |
| `border` | цвет обводки | цвет |
| `borderwidth` | толщина обводки | число |
| `radius` | скругление углов | число; для `shape: square` не нужен |
| `shape` | силуэт | `round`, `square`, `circle`, `triangle`, `diamond`, `line`, `none` |
| `shadow` | мягкая тень под элементом | `true` / `false` |
| `opacity` | прозрачность элемента | `0`…`1` |
| `scale` | масштаб относительно своего места | `1` — исходный |
| `offsetx`, `offsety` | сдвиг от своего места, в пикселях | число |
| `padding` | внутренний отступ | число |
| `gap`, `spacing` | промежуток между детьми | число |
| `visible` | показывать ли элемент | `{условие}` |
| `width`, `height` | размер | число, `%`, `fill`, `auto` |
| `font` | шрифт | `"Segoe UI"` |
| `fontsize` | размер шрифта | число |
| `bold` | жирный | `true` / `false` |
| `align` | выравнивание текста | `left`, `center`, `right` |
| `icon` | иконка | имя встроенной или путь к файлу |
| `iconsize` | размер иконки | число |

Отдельно у контейнеров (`row`, `column`, `stack`):

| Свойство | Что делает | Значения |
|---|---|---|
| `justify` | раскладка вдоль оси | `start`, `center`, `end` |
| `cross` | поперёк оси | `start`, `center`, `end` |

Отдельно у виджетов с содержимым:

| Тип | Свойство | Что делает |
|---|---|---|
| `box`, `label` | `text` | текст, можно с `{...}` |
| `button` | `action` | что сделать по клику (раздел 8) |
| `button` | `tooltip` | текст подсказки (читается, но пока не рисуется) |
| `bar`, `progress` | `value` | текущее значение |
| `bar` | `max` | максимум, по умолчанию `1` |
| `bar` | `fill`, `accent` | цвет заполненной части |
| `bar` | `orientation` | `horizontal` (по умолчанию) или `vertical` |

Про `bar` и `max`: если писать `value: "{sys.cpu}"` (это 0…100), а `max` не
указывать, полоса сама поделит на 100. Если значение — доля (`media.progress`
даёт 0…1), указывай `max: 1`.

## 7. Поверхности

`surface` — это отдельное окно поверх рабочего стола. Свойства ставятся прямо в
её тело, рядом с элементами:

| Свойство | Что делает | Значения |
|---|---|---|
| `position` | к какому краю прижаться | `top`, `bottom`, `left`, `right`, `center`, `float` |
| `anchor` | выравнивание вдоль края | `left`/`start`, `center`, `right`/`end` |
| `margin` | отступ от края | число (по умолчанию `8`) |
| `offsetx`, `offsety` | дополнительный сдвиг | число |
| `width`, `height` | размер окна | число, `%`, `auto` (по содержимому) |
| `monitor` | монитор | `-1` — под курсором, `0`, `1`, `2`… — номер |
| `opacity` | прозрачность всего окна | `0.05`…`1` |
| `clickthrough` | клики проходят сквозь | `true` / `false` |
| `ontop`, `topmost` | всегда сверху | по умолчанию `true` |
| `enabled` | создавать ли поверхность | `true` / `false` |

Для `position: float` окно ставится от левого верхнего угла монитора плюс
`offsetx`/`offsety` — так делаются плавающие виджеты в произвольном месте.

Поверхность никогда не забирает фокус и не появляется в панели задач: клик по
кнопке на панели не сбивает активное окно.

Хочешь спрятать поверхность, не удаляя её, — поставь `enabled: false`. Так
сделаны все примеры в `examples.nx`.

## 8. Кнопки и действия

У `button` есть `action` — что делать по клику:

| Действие | Что происходит |
|---|---|
| `rofi`, `menu` | меню приложений |
| `launcher` | лончер nyxWM |
| `settings` | окно настроек |
| `terminal` | новое окно терминала |
| `hide` | спрятать лончер |
| `reload` | перечитать все `.nx` файлы |
| `exit` | закрыть nyxWM |
| `command:путь`, `run:путь` | запустить программу |

Для запуска программы нужны кавычки: `action: "command:explorer"`. Можно и с
аргументами: `action: "command:notepad C:\\tmp\\note.txt"`.

## 9. Анимации

```nx
animation имя:
    duration: 200ms        // сколько длится
    easing: back-out       // кривая
    loop: true             // повторять
    alternate: true        // туда-обратно
    {
        opacity: 0         // кадр 0%
        scale: 0.7
    }
    50% {
        opacity: 1
    }
    100% {
        opacity: 1
        scale: 1
    }
```

Тело анимации — отступом или скобками. Кадры пишутся `{ ... }`; у кадра можно
указать процент (`50%`) и свою кривую (`50% ease-in { ... }`). Если процент не
указан, первый кадр считается за `0%`, а все следующие — за `100%`, поэтому у
средних кадров процент лучше писать явно.

Подключается свойством `animate: имя` на элементе.

Кривые (`easing`): `linear`, `ease-in`, `ease-out`, `ease-in-out`, `sine`,
`sine-in`, `sine-out`, `bounce-out`, `back-out`, `step`.

Анимировать (плавно менять между кадрами) можно: `opacity`, `scale`,
`offsetx`, `offsety`, `radius`, `borderwidth`, `width`, `height`,
`padding`, `gap`/`spacing`, `fontsize`, `iconsize`, `background`, `foreground`,
`border`. Остальные свойства на кадрах просто переключаются.

Свои анимации объявляй в своём файле — как `pulse` в `examples.nx`. Объявленные
в `theme.nx` (`pop`, `breathe`, `slide-in`, `glow`, `sweep`) доступны везде.

Анимация идёт на реальном времени и живёт на кадровом такте окна: на 165 Гц
обновление 165 раз в секунду, ничего не «дёргается».

## 10. Данные: `{namespace.key}`

Внутри `{...}` можно читать системные данные. Значение пересчитывается каждый
кадр — часы идут, трек меняется, счётчик окон живой.

Общий вид: `{time.hm}`, `{sys.cpu}`, `{win.title(0)}`, `{media.artist}`.

### `time.*` — время и дата

| Ключ | Значение |
|---|---|
| `hh`, `mm`, `ss` | часы, минуты, секунды числом |
| `hm`, `hms` | `"14:35"`, `"14:35:09"` |
| `hour`, `hour12`, `minute`, `second`, `ampm` | части времени |
| `year`, `month`, `day` | дата числом |
| `weekday`, `monthname`, `weekdayname` | день недели числом / названия |
| `dayofyear`, `week` | номер дня в году, номер недели ISO |
| `date` | короткая дата системы |
| `iso` | `2026-11-17T14:35:09` |
| `unix` | секунды Unix |
| `timezone` | имя часового пояса |
| `utc` | время UTC, `ЧЧ:ММ` |
| `uptime` | сколько работает Windows (текстом) |

### `sys.*` — система

| Ключ | Значение |
|---|---|
| `language`, `lang` | язык, `"ru"` |
| `region`, `country` | страна/регион, `"RU"` |
| `culture` | `"ru-RU"` |
| `keyboardlayout` | текущая раскладка |
| `cpu` | загрузка ЦП, % |
| `mem` | загрузка памяти, % |
| `memused`, `memfree`, `memtotal` | память в мегабайтах |
| `battery` | заряд, % (пусто, если батареи нет) |
| `batterystate` | текст состояния |
| `acpower` | питание от сети, `true`/`false` |
| `screenwidth`, `screenheight` | разрешение основного экрана |
| `refreshrate` | герцы монитора |
| `dpi`, `scale` | DPI и масштаб (1.5 = 150%) |
| `monitorcount` | число мониторов |
| `hostname`, `username` | имя машины и пользователя |
| `processcount`, `processes` | число процессов |
| `appname` | `"nyxWM"` |
| `idle` | секунд без ввода |

### `win.*` — окна

| Ключ | Значение |
|---|---|
| `count` | окон всего |
| `visible` | не свёрнутых |
| `minimized` | свёрнутых |
| `foreground` | заголовок активного окна |
| `foregroundclass`, `foregroundprocess`, `foregroundpid` | про активное окно |
| `hasfullscreen` | есть ли полноэкранное окно, `true`/`false` |
| `list`, `minimizedlist` | заголовки списком через запятую |
| `title`, `class`, `process`, `pid`, `monitor` | про окно по номеру: `{win.title(3)}` |

Номер в скобках — с нуля, `0` это активное окно. Вместо номера можно писать имя
процесса или класса: `{win.title(chrome)}`.

### `media.*` — что играет

| Ключ | Значение |
|---|---|
| `title`, `artist`, `album`, `albumartist`, `track`, `genre` | теги |
| `source`, `app` | приложение-источник |
| `status` | текст состояния |
| `playing`, `paused`, `stopped` | флаги |
| `position`, `duration`, `remaining` | секунды |
| `progress` | доля от `0` до `1` |
| `hassession` | есть ли вообще сессия |
| `canplay`, `canpause`, `canskip`, `canseek` | что умеет плеер |

Если ничего не играет, все текстовые поля пустые — `default(...)` подставит своё.

## 11. Выражения

Внутри `{}` работает маленький язык выражений.

```nx
text: "{time.hm}"
text: "{round(sys.cpu)}%"
text: "{default(media.title, 'ничего не играет')}"
visible: "{sys.battery >= 0}"
background: "{if(sys.cpu > 80, '#f7768e', '#7aa2f7')}"
text: "{upper(sys.username)}: {len(win.list)}"
```

**Операторы:** `+ - * / %`, сравнения `== != < <= > >=`, логика `&& || !`,
условие `? :`.

**Функции:**

| Функция | Что делает |
|---|---|
| `upper(s)`, `lower(s)`, `trim(s)` | регистр и обрезка пробелов |
| `len(s)` | длина |
| `number(s)` | превратить текст в число |
| `round(n)`, `round(n, знаков)` | округление |
| `floor(n)`, `ceil(n)`, `abs(n)` | вниз, вверх, модуль |
| `min(a, b)`, `max(a, b)`, `clamp(n, мин, макс)` | границы |
| `pad(n)`, `pad(n, ширина)` | дополнить нулями: `pad(7)` → `07` |
| `concat(a, b, …)` | склеить |
| `truncate(s)`, `truncate(s, длина)` | обрезать с `…` |
| `percent(n)` | `73%` |
| `clock(секунды)` | `3:07` |
| `if(условие, да, нет)` | выбор |
| `default(значение, запасное)` | запасное, если пусто |

Строки в выражениях — в одинарных или двойных кавычках, но внутри строки `.nx`
удобнее одинарные: `"{default(media.title, 'тишина')}"`.

## 12. Иконки

Встроено 47 иконок, рисуются кодом, поэтому масштабируются без потерь:
`play`, `pause`, `stop`, `next`, `prev`, `music`, `volume`, `mute`, `search`,
`apps`, `grid`, `power`, `settings`, `terminal`, `window`, `close`, `plus`,
`minus`, `check`, `dot`, `circle`, `square`, `ring`, `triangle`, `diamond`,
`star`, `heart`, `sun`, `moon`, `cloud`, `battery`, `cpu`, `ram`, `clock`,
`calendar`, `globe`, `wifi`, `pin`, `bell`, `chevron-up`, `chevron-down`,
`chevron-left`, `chevron-right`, `arrow-up`, `arrow-down`, `arrow-left`,
`arrow-right`.

Неизвестное имя не рисует ничего (вместо падения) — опечатка даёт пустое место.

### Своя картинка вместо иконки

```nx
button:
    icon: "icons/favicon.png"
    iconsize: 20
```

Поддерживаются `png`, `jpg`, `jpeg`, `bmp`, `gif`, `ico`, `tif`, `webp`.
Путь относительный — считается от файла `.nx`, в котором написан, поэтому
картинки удобно держать рядом: `Res\Nx\icons\`. Абсолютный путь тоже работает.
Картинка вписывается в квадрат `iconsize` с сохранением пропорций. Файл
читается один раз и кэшируется; если файла нет — в лог попадёт строка
`nx: icon file '...' not found`, а элемент просто останется без картинки.

Работающий пример — кнопка `#files` в `examples.nx` с `icon: "icons/test.png"`.

## 13. Рецепты

### Добавить кнопку на панель

Открой `bar.nx`, найди `row:` внутри `surface #bar:` и добавь рядом с другими:

```nx
        button #music:
            action: "command:notepad"
            icon: music
            iconsize: 16
            width: 32
            height: 32
            radius: $radius-small
            background: $bg-hover
            foreground: $fg
            animate: pop
```

Сохрани — кнопка появится сразу.

### Убрать градиенты и скругления, сделать плоские квадраты

```nx
button:
    shape: square
    background: #2b2f3a     // один цвет, без второго в списке
    radius: 0
    borderwidth: 1
    border: #3a3f4b
```

### Свой виджет в углу

```nx
surface #weather:
    enabled: false
    position: bottom
    anchor: right
    width: auto
    height: auto
    margin: 16

    column:
        padding: 10
        gap: 4
        background: #cc12151c
        radius: 12

        row:
            gap: 8
            cross: center

            box:
                icon: sun
                iconsize: 16
                foreground: $warn

            label:
                text: "{sys.language} / {sys.country}"
                fontsize: $size-small
                foreground: $fg
```

`enabled: false` — держи выключенным, пока не убедишься, что нравится.

### Своя анимация

```nx
animation jump:
    duration: 500ms
    loop: true
    alternate: true
    easing: bounce-out
    {
        offsety: 0
    }
    100% {
        offsety: -6
    }
```

и на элементе: `animate: jump`.

### Хочу свою палитру

Поменяй токены в `theme.nx` — изменятся все поверхности сразу. Или объяви свои в
своём файле с теми же именами: файлы из `%AppData%\nyxWM\nx\` читаются позже и
перекрывают встроенные.

### Временно всё выключить

`enabled: false` в теле нужной `surface`. Полностью отключить систему `.nx`
нельзя — только по одной поверхности.

## 14. Что делать, если не работает

| В логе | Причина |
|---|---|
| `Expected Colon but found ... at 12:9` | в строке 12, колонка 9 — опечатка: забыто `:`, значение без кавычек, лишний пробел |
| `Expected Identifier but found '1'` | значение с `:` или `/` не взято в кавычки |
| `'button#play' at 8 declares an element but has no block` | у элемента с `#именем` нет тела — добавь отступ или `{}` |
| `Unclosed block for 'surface' opened at 4` | не закрыта `}` |
| `icon file '...' not found` | нет картинки по пути |
| `nx: ... failed: ...` | ошибка при построении поверхности, текст исключения рядом |
| ничего не изменилось после сохранения | файл лежит не в `Res\Nx\` и не в `%AppData%\nyxWM\nx\`, или у поверхности `enabled: false` |

Номер в сообщении — `строка:колонка`, колонка считается с единицы.

## 15. Что где лежит

| Файл | Что внутри |
|---|---|
| `theme.nx` | палитра, размеры, общие анимации. Поверхностей не объявляет |
| `bar.nx` | верхняя панель: лончер, часы, трек, загрузка ЦП, окна, батарея, кнопки |
| `examples.nx` | три выключенные поверхности с примерами: плоские кнопки, фигуры, своя анимация, своя картинка |
| `icons\` | картинки для свойства `icon` |

Код системы: `Core\Nx\` — лексер, парсер, AST; `Core\Nx\Data\` — поставщики
данных; `Core\Nx\Runtime\` — стили, виджеты, поверхности, анимации.
